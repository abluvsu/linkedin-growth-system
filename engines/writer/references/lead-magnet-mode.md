# Lead Magnet Mode Configuration

This file translates global lead magnet philosophy into platform-specific LinkedIn mechanics.

### [Section 1: State Initialization]
`Lead_Magnet_Mode = [ACTIVE | INACTIVE]`

### [Section 2: The Value/Tease Architecture]
- **Rule of 3:** The post body must extract exactly 3 high-value, standalone tips, insights, or data points directly from the resource. The text must be immediately useful *without* downloading the asset.
- **The Gate:** The hook and closing must position the lead magnet as the tool that automates, accelerates, or scales those 3 insights (e.g., templates, frameworks, checklists).

### [Section 3: Conditional CTA Mechanics]
Evaluate the input context and apply one of these exact structures:
- **Condition A (High Friction/High Value - e.g., Deep-dive Ebook/Guide):** Use Comment-Baiting to drive algorithmic velocity. 
  *Format:* "Comment '[Keyword]' below and I'll DM you the access link."
- **Condition B (Low Friction/High Utility - e.g., 1-page Notion Template/Cheat Sheet):** Use Link-in-Comments to reduce conversion drop-off.
  *Format:* "Grab the completely free template via the link in the comments below."
- **Condition C (Direct Outbound):** If specified by the user, provide the raw URL cleanly.
